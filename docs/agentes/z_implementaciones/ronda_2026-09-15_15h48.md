## Detalle por bloque

### Bloque 1 — `--min-score n` (puerta de postura)

- **Semántica:** exit 3 cuando `hardeningScore(p.Findings) < n`. Es la única puerta que mira una CIFRA y no un recuento: un host con 30 hallazgos LOW (score pésimo) pasa `--fail-on high` en verde pero la puerta de postura lo tumba — el caso real de "la superficie no tiene HIGHs pero es un queso suizo".
- **Validación fail-fast:** n < 0 o n > 100 → exit 2 en `run()` antes de escanear (contrato `--fail-on`); 0 = desactivada (y es un no-op natural: el score se clampea a 0, `score < 0` es imposible — el zero-value es a la vez el estado desactivado y una configuración inofensiva, documentado en la struct).
- **Borde exacto pineado por test:** `score < floor` tripia; `score == floor` NO (87 < 87 es falso — el suelo es un mínimo que la máquina DEBE alcanzar, "at the floor is passing"); el mensaje lleva ambos números: `score gate: hardening score 87 < 90 — exit 3`.
- **Precedencia de mensaje más baja de las tres:** política → regresión → postura. Un veredicto que NOMBRA su hallazgo le gana al genérico "score bajo" para el operador que lee el log de CI (las tres salen 3 igualmente — tests de precedencia contra ambas).
- **Contrato ronda 8 intacto:** puerta en verde → caída al 0/1 clásico (E2E: `--quiet --min-score 10` en esta máquina → exit 1, el exploit implícito sin root NO queda enmascarado).
- **Composición E2E real:** `--quiet --min-score 70 --baseline base.json --fail-on-new` → 3; `--quiet --min-score 70` a secas (score 40 de esta máquina) → 3 con mensaje; `--min-score 150` → exit 2.

### Bloque 2 — `--completion bash|zsh|fish` (nuevo `completion.go`)

- **Generación desde la fuente de verdad:** `completionFlagNames()` construye un FlagSet PRIVADO vía `registerFlags` — la misma función que `run()` y que el test de paridad usan. Un flag añadido a `registerFlags` aterriza en la siguiente completion SIN tocar nada más, y el script jamás puede ofrecer un flag que el binario rechace (la clase de deriva que la paridad hermética caza, ahora imposible también aquí).
- **Tres shells reales:** bash (`complete -F _autoprivilege_completions` con compgen sobre la lista de `--flags`), zsh (`#compdef` + `_arguments` con specs `(--flag)"--flag"[desc]` y escape de comillas/corchetes), fish (`complete -c autoprivilege -l flag -d 'desc'` con escape de comillas). Las descripciones son la PRIMERA LÍNEA del usage string de cada flag (recortadas para tooltip). `--help` se añade manualmente (el paquete flag lo sirve builtin).
- **Fail-fast:** shell desconocida → error con las válidas en el mensaje (`valid: bash, zsh, fish`) → exit 2 en `run()`; case-insensitive (`BASH` funciona — test).
- **Modo documentación:** imprime y sale sin escanear (exit 0), mismo contrato que `--list-gtfo`/`--list-vectors`.
